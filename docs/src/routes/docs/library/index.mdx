# Library

Tombi's formatter and linter can be called in-process from Python and Node.js.

| Language | Package |
| --- | --- |
| [Python](/docs/library/python) | `tombi-lib` |
| [Node.js](/docs/library/nodejs) | `tombi-lib` |

The Node.js `tombi-lib` package is a native addon for server-side Node.js and does
not run in browsers. For browsers, use the [WebAssembly packages](/docs/wasm)
(`tombi-wasm-lib` / `tombi-wasm-lsp`) instead.
