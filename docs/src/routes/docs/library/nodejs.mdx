# Node.js

## Install

```sh
npm install @tombi-toml/tombi-lib
```

## Usage

```ts
import { format, lint } from "@tombi-toml/tombi-lib";

const { formatted } = await format("key=1", "example.toml");
console.log(formatted); // key = 1

const { diagnostics } = await lint("key =", "example.toml");
for (const diagnostic of diagnostics) {
  console.log(diagnostic.level, diagnostic.message);
}
```

## Configuration

By default, `tombi.toml` is searched from the current directory.
Pass `config` to use an in-memory configuration instead:

```ts
await format(source, "Cargo.toml", { config: "[format.rules]\nindent-width = 4\n" });
```
