Formatter CLI Usage

Tombi's formatter can be run via the CLI.

# If you have `tombi.toml` in your project, Format all TOML files in the project,
# if not, it will format all TOML files in the current directory
tombi format

# Format a single file
tombi format path/to/file.toml

# Format multiple files
tombi format path/to/file1.toml path/to/file2.toml

# Format all TOML files in a directory
tombi format .

# Format files using glob pattern
tombi format **/*.toml

# Format from standard input
cat Cargo.toml | tombi format -
🗒️Note

If only warnings are logged during formatting, such as a schema that could not be fetched, Tombi will exit successfully by default.
However, you can use the --error-on-warnings option to make Tombi exit with an error when warnings are present.

See Diagnostics Output to report unformatted files in machine-readable formats such as JUnit and SARIF.
