Formatter

The most impressive feature of Tombi's formatter is its Auto Sorting, which sorts entries by default based on JSON Schema metadata retrieved from Schema Store.

Tombi was originally designed as a uniform formatter inspired by Black. To welcome users coming from Taplo, this policy was gradually relaxed, and Tombi has evolved into a formatter with many options.

Tombi's default formatting options reflect its core philosophy. You can also influence formatting while typing by using Magic Trailing Comma or Magic Trigger instead of configuration.
